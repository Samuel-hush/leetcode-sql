# LeetCode SQL 面试题集

## 这是什么
整理的 LeetCode Database 高频 SQL 题，按考点分类，共 20 题，用于面试练习。

每个 .sql 文件按「题目 → 考点 → 要求 → 涉及表 → 套路 → 答案」记录，
重点是「套路」：看到一个题型，立刻反应出该用什么函数、表怎么连、边界怎么处理。

## 目录结构
- 01_排名/（3 题）
- 02_第N高/（2 题）
- 03_连续出现/（2 题）
- 04_自连接/（2 题）
- 05_JOIN与聚合/（2 题）
- 06_增删改/（2 题）
- 07_分组过滤/（3 题）
- 08_条件与相邻交换/（3 题）
- 09_综合Hard/（1 题）

## 覆盖考点
DENSE_RANK / RANK / ROW_NUMBER（排名）、LIMIT OFFSET + IFNULL（第N高）、自连接（连续/相邻）、
LEFT JOIN + IS NULL、DELETE/UPDATE、GROUP BY + HAVING、CASE WHEN、占比（SUM 条件转 0/1）

## 怎么用
每个 .sql 文件：先看「套路」记思路，再默写答案；每道题默写 3 遍直到不看答案能一遍写对。
